## 验证场景

- 运行启动、完成、失败、取消、重新配置、关闭及 EOF；审批按中断、运行、租户和用户身份恢复。
- 会话删除先等待活跃任务退出，再结束该会话作业，最后删除持久状态。
- 文件权限、越界、符号链接、BOM、换行、写锁、取消、原子替换失败与临时文件清理。
- 补丁预检、重复更新、移动、更新后删除和部分提交；applied 保留操作顺序，files 报告最终差异。
- Shell/Python 进程树、超时、输出截断、环境过滤与后台作业隔离。
- 路由、指令、摘要索引、预算、步数、流式重试及原生子任务权限。
- 临时 SQLite 数据跨资源重开恢复；wheel 独立导入。测试不得操作真实用户数据库。

## 结果

- 配置归入 HarnessSettings，运行按 AgentRuntime、RunManager、SessionService 分工；协议由 StdioServer 负责。

- 全包启用类型检查，增加依赖方向和类结构约束；各目录指南与架构说明已更新。
