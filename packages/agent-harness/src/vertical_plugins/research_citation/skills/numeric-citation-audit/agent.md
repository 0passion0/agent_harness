# 数字引文审计技能目录 (numeric-citation-audit) - Agent 指南与规范

## 目录定位与职责
`numeric-citation-audit/` 包含面向大语言模型的数字引文核验专属技能定义。

## 核心文件
- `SKILL.md`：核心技能说明书，包含 Frontmatter 声明与操作指南，定义了数字引文识别规则、未决断言处理流程以及报告输出规范。

## 维护规范
1. **指令边界明确**：技能描述必须明确何时由主智能体直接使用 `scan_numeric` 工具，何时委派给专门的工作流子智能体。
2. **反越权约束**：必须重申不得假造核查通过结果，所有结论必须以工具返回的审计对象为准。
