# 日志与可观测性模块 (vertical_harness/log) - Agent 指南与规范

## 1. 目录定位与职责
`vertical_harness/log/` 负责全框架的生产级结构化日志记录与链路可观测性追踪管理。
确保执行过程具备完整审计轨迹的同时，严格践行敏感信息屏蔽与用户隐私保护。

## 2. 核心类与文件
- `__init__.py`：统一导出类 `HarnessLogging`、`LangSmithSettings`、`TracingSession`。
- `logging.py` (`HarnessLogging`)：
  - 核心结构化日志管理器，提供 JSON / KV 格式输出配置、上下文追踪元数据注入及动态日志级别调整。
  - 内置严格的关键词与数据模式脱敏机制。
- `observability.py` (`TracingSession`)：
  - LangSmith 链路追踪会话管理器，提供追踪上下文环境激活、会话标记及安全生命周期守护。

## 3. 关键交互与设计约束
1. **零隐私泄漏（Zero-Leakage）硬约束**：
   - 严禁在任何日志输出中打印用户对话原始内容、上传附件明文、API 密钥凭证或任意未经脱敏的复杂输入对象。
2. **幂等性配置**：
   - 日志初始化与配置必须具备幂等性，多次调用不得产生重复的日志 Handler 或日志格式错乱。
3. **上下文可追溯**：
   - 结构化日志必须包含标准的执行上下文元数据（如 `run_id`、时间戳、模块名），方便问题定位与全链路回放。
