# 评测模块 (vertical_harness/evaluation) - Agent 指南与规范

## 目录定位与职责
`vertical_harness/evaluation/` 提供了完备的离线（Offline）与在线（Online）智能体评测体系。负责评测数据集加载、目标系统适配、指标打分、用户反馈采集以及与 LangSmith 评测平台的双向同步。

## 核心组件与文件
- `cli.py`：评测子系统的命令行入口，支持运行离线批处理基准测试或上传黄金测试集。
- `config.py`：定义评测配置模型 `EvalConfig`，控制并行数、重试策略与指标阈值。
- `datasets.py`：通用与领域评测数据集解析器，支持从本地 JSONL 或 LangSmith 读取测试样本。
- `feedback.py`：用户在线反馈捕获，将点赞/点踩与评审批注持久化并绑定至对应的 Run ID。
- `offline.py`：离线批量评测执行引擎，调用评测目标并收集各项细粒度指标。
- `online.py`：在线运行时评测监听器，轻量级评估实时会话质量。
- `scoring.py`：评测打分器实现，支持规则打分（精确匹配、重合度）与大模型裁判（LLM-as-a-Judge）。
- `targets.py`：评测目标适配层，统一本地函数调用、智能体工作流与远程端点的评测接口。

## 关键约束与安全规范
1. **测试与生产隔离**：评测运行必须指定独立的租户标识与临时工作区，避免污染生产数据库。
2. **打分确定性与幂等性**：规则评分器必须纯函数化，LLM 裁判评分必须限制温度并固定评测 Prompt 模板。
3. **指标脱敏聚合**：评测日志和指标报告仅保留聚合统计值（如 Accuracy、Recall、Latency），不记录被测原稿明文。
