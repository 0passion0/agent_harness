# 示例目录 (examples) - Agent 指南与规范

## 目录定位与职责
`examples/` 目录存放用于演示系统功能、验证端到端运行流程以及进行评测的数据集与配置样例。该目录帮助开发者和自动化 Agent 快速理解系统的实际输入输出格式。

## 子目录结构
- `evaluation/`：存放离线评估与基准测试所需的黄金测试集与标注样例（如论文引文核查数据集）。

## Agent 交互与使用规范
1. **示例真实性与脱敏**：所有示例数据中均不得包含任何真实私密数据、API 凭证或私有业务涉密内容。
2. **格式规范性**：JSONL 或 YAML 数据集必须严格遵循 Pydantic 模型的验证结构（如 `CitationCheckDatasetItem` 等）。
3. **保持轻量**：样例数据集重点在于覆盖典型场景、边界用例与异常格式用例，避免引入体积过大的冗余文件。
