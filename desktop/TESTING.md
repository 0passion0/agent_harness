## 行为范围

- Python 后端通过 `vertical_harness.desktop` 启动，桌面目录不再承载 Python 运行代码或重复插件源码。
- 插件目录来自后端安装的插件 entry points；前端使用通用插件与工作流信息，不绑定具体插件名称。
- 在本项目 `.venv` 直接调用插件目录，已验证能发现数据分析和引文审查工作流及各自独立技能。
- 输入框 `/` 先选择插件或技能分类。插件选择仅对当前一轮授权；技能选择与插件授权独立。
- 聊天内工作流卡片按实际运行标识和父子事件关联节点、工具及终态，并随对应用户消息保存。暂停恢复继续使用原运行标识。
- Token 消耗来自模型返回的用量，按会话汇总时包含子代理请求；上下文占用是估算，未知区块显示“未统计”。
- 已发布产物按会话运行记录恢复，其他会话的产物不会自动混入。
